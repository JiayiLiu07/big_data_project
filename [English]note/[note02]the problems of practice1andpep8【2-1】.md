## 2. PEP8: Coding Style Guidelines Widely Accepted by the Python Community

1. Indentation
- Requires 4 spaces for indentation. Tabs or mixed spaces/tabs are prohibited.

2. Space Usage

- Add spaces before and after operators: +=, -=, *, /, etc.
- Add spaces after commas, colons, and semicolons, but not at the beginning or end of parentheses.

3. String Quotes

- Prefer double quotes ("") for non-multiline strings.
- Multi-line strings or strings containing single quotes should use triple double quotes """..."""" or triple single quotes '''...'''.

And so on and so forth. In short: every time you write code, you should check whether it complies with PEP8.
