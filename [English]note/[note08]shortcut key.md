## Click inside the box

`shift + tap` // `tap` **Change indent**

You can box an entire paragraph to change indent

`ctrl + A` **Select all** (A = All)

`ctrl + /` **Comment**

`shift + Alt + A` **Multi-line comment**

`shift + <` **Select left**

## Click outside the box
`ctrl + F` **Find** (F = Find)

`ctrl + S` **Save** (S = Save)

`B + enter` **Insert a new cell below** (B = Below)

`A + enter` **Insert a new cell above** (A = Above)
