1. spark是什么？
引擎
2. 核心特点
- 内存计算：Spark 的核心是弹性分布式数据集（RDD），它允许数据存储在内存中，从而显著提升计算速度。
- DAG 执行引擎：通过有向无环图（DAG）的执行方式，优化了任务调度和执行过程。
- 容错机制：Spark 具备强大的容错能力，能够在数据丢失或节点故障时自动恢复。
- 通用性：支持多种数据处理任务，如 SQL 查询、实时流处理、机器学习等。

3. 主要功能模块
- Spark SQL：用于执行结构化查询，支持 SQL 语句。
- Spark Streaming：用于实时数据流处理。
- MLlib：机器学习库，支持分类、回归、聚类等任务。
- GraphX：图计算库，用于分析图数据。
- Spark Core：核心组件，提供基础功能和 RDD 支持。

5. 与 Hadoop 的区别
- 性能优势：Spark 支持内存计算，而 Hadoop 的 MapReduce 主要依赖- 磁盘存储，因此 Spark 在速度上更快。
- 灵活性：Spark 提供多种数据处理方式，而 Hadoop 主要专注于批处理。
- 易用性：Spark 提供丰富的 API（如 Python、Java、Scala），开发更加便捷。
