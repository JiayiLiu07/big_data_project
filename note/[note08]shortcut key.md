## 点进框内

`shift + tap` // `tap` **更改缩进**
    
    可以将一整段框起来 更改缩进


`ctrl + A` **全选** (A = All)

`ctrl + /` **注释**

`shift + Alt + A` **多行注释**

`shift + <` **向左框选**

## 点进框外
`ctrl + F` **查找** (F = Find)

`ctrl + S` **保存** (S = Save)

`B + enter` **在下方插入新的单元格**(B = Below)

`A + enter` **在上方插入新的单元格**(A = Above)
