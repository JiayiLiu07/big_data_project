3. URL? the relationship with IP?
- URL 长什么样
https://www.example.com:443/docs/index.html?id=1#top
    - 拆成：
        - 协议（https）
        - 主机名（www.example.com）
        - 端口（443，可省略）
        - 路径（/docs/index.html）
        - 查询串（?id=1）
        - 片段（#top）
- 与 IP 的对应流程
    - 浏览器拿到 URL → 提取主机名 www.example.com
    - DNS 解析 → 返回 93.184.216.34（这就是 IP）
    - TCP 三次握手连到 93.184.216.34:443
    - 发送 HTTP 请求：GET /docs/index.html?id=1 …
    - 服务器按路径、查询串、片段返回网页
-  小结
    - URL 面向人、包含“找谁+要什么资源”的全部信息。
    - IP 面向网络路由，只解决“数据包该送到哪台机器”。
    - 一个域名可以对应多个 IP（负载均衡）；一个 IP 也可以挂多个域名（虚拟主机）。
    - 域名就是 难记的数字IP地址 的“易记别名”（eg. www.example.com）

4. NAT（网络地址转换）--> NAT设备（通常是路由器或防火墙）位于私有网络和公共网络之间。
- 将私有IP地址转换为公有IP地址（反之亦然）
- 主要解决IPv4地址枯竭的问题，并能提供一定的网络安全隔离。
    - IPv4地址短缺： 公有IP地址（可以被互联网直接访问的IP地址）数量有限。大多数组织（家庭、公司）无法获得足够多的公有IP地址来分配给内部所有设备。
    - 私有IP地址： 为了解决地址短缺，我们使用私有IP地址（例如192.168.x.x, 10.x.x.x, 172.16.x.x - 172.31.x.x），这些地址在互联网上是不可路由的，只能在局域网内部使用。
    - 访问互联网： 如果所有设备都只能使用私有IP地址，它们就无法直接访问互联网上的服务器。

## 二、 概念梳理以及它们之间的关系：

#### （一）、 概念梳理
*   **运营商 (ISP) :** 提供网络连接服务的公司。他们拥有庞大的网络基础设施（包括光纤、服务器、路由器等），并向用户（家庭、企业等）提供接入互联网的能力。
    - 互联网 叫 公网
*   **光猫 :** 光猫是运营商为家庭或企业用户提供的接入设备。它的主要作用是将光信号转换为电信号，以便家里的设备（如路由器、电脑）能够理解和使用。反之，它也将电信号转换为光信号，通过光纤传回运营商的网络。光猫通常位于用户网络的入口处。
    - （核心）**用户家里的宽带接入，最终是通过光纤连接到运营商的网络。**
*   **路由器 (Router):** 路由器是连接不同网络的设备。它的核心功能是根据IP地址进行数据包的转发，决定数据从一个网络到达另一个网络的最优路径。在家用场景中，路由器通常连接光猫和内部网络（如电脑、手机、交换机）。路由器是实现互联网连接的关键设备。
*   **交换机 (Switch):** 交换机主要用于连接**同一网络**内的设备。它根据MAC地址在局域网（LAN）内部高效地转发数据帧。通常在一个家庭或办公室网络中，交换机（有时集成在路由器中）负责连接多台电脑、打印机等设备。
    - 不一定是连接电脑、打印机，是什么设备无所谓；只要有网卡才能插交换机。
*   **MAC地址 :** MAC地址是网卡（Network Interface Card）的**物理地址**，也称为硬件地址。它由网卡制造商在全球范围内唯一分配，用于在**数据链路层**标识网络设备。MAC地址是固定的，并且与设备绑定。
*   **IP地址 :** IP地址是**逻辑地址**，用于在**网络层**标识网络中的设备。IP地址是可配置的，用于在不同的网络之间路由数据。我们通常接触到的IP地址是公网IP（由运营商分配，用于访问互联网）和私网IP（在家庭或企业局域网内使用，由路由器分配）。
*   **网卡 :** 网卡是计算机或其他网络设备的硬件接口，它负责将数据转换成可以在网络上传输的信号（电信号、光信号等），并将接收到的信号转换回数据。每块网卡都有一个唯一的MAC地址。
*   **以太网协议 :** 以太网是一种广泛使用的局域网技术标准。它定义了数据帧的格式、MAC地址的寻址方式以及在共享介质上的访问控制机制。以太网协议主要工作在**物理层**和**数据链路层**。

#### （二）、 它们之间的关系 
1.  **运营商提供连接，光猫是接入的桥梁：** 运营商通过光纤将互联网接入到用户家中，光猫负责将运营商的光信号转换成家用设备可以处理的电信号。
2.  **路由器连接不同网络，实现互联网访问：** 路由器将家庭局域网（由光猫连接到外部网络）与外部网络（互联网）连接起来。它负责根据IP地址将数据包从内部网络发送到外部网络，或从外部网络发送到内部网络。
3.  **交换机连接同一网络内的设备：** 如果需要连接多台设备在局域网内通信，可以使用交换机（或路由器自带的交换功能）。交换机通过MAC地址在局域网内高效地转发数据。
4.  **网卡是通信的物理接口，拥有MAC地址：** 任何需要参与通信的设备（电脑、手机、路由器、交换机等）都必须有网卡。网卡有其唯一的MAC地址。
5.  **MAC地址用于局域网内的寻址，IP地址用于跨网络寻址：** MAC地址在数据链路层用于在同一网络段内精确地找到目标设备。IP地址在网络层用于在不同网络之间找到目标设备。

## 三、 TCP/IP五层模型
## 物理层
没有寻址功能
媒介：电缆、光纤、双绞线等
1. 两种信号（信号形态）：
- 模拟信号：连续的，像声音一样
- 数字信号：本质是离散的
2. 两种信号（物理载体/介质）：
- 电信号：用电压/电流在金属导体上传输。
- 波信号：用电磁波（无线或光纤中的光波）传播。
3. 电信号和波信号既可以是模拟的又可以是数字的

## 数据链路层
MAC -->【我是谁，我要发给谁，什么信息，检查信息是否会出错】--> 中间点（switch（switch table）--> 发给指定的人


#### 1. 网卡是个硬件：是计算机连接到网络介质（媒介：电缆、光纤等）的物理接口，将计算机内部的数字信号转换成可以在铜线、光纤或空气中传播的物理信号
- 藏在键盘底下 （准确来说：集成在主板上，主板在键盘下面）
- 分为有线和无线：无线网卡发波和接收波；有线网卡提供插口。
- 存放着mac地址（物理地址）
- 有几个网卡就有几个物理地址



#### 2. 交换机（switch）：mac地址
- 有个switch table：寻址功能，包含着 插口跟物理设备对应的关系
- 有容错功能，因为IP地址会变化
- 连接同一栋楼里的设备（小网络里可以有多个交换机，交换机之间可以相连接）


#### 3. 以太网协议：像写邮件一样,包含寄件人信息（地址），收件人信息，内容
- 不是网，是协议
【ps：Wi-Fi协议：实现这协议的叫Wi-Fi】

（二）、广州PC 中山路由器/交换机 珠海PC 
广州PC 中山路由器/交换机 珠海PC 
我要从广州发送一条信息 --> 相当于一个大包裹
1. 应用层：被裹上HTTP等协议；大包裹被分割成5个小包裹，发送
2. 传输层：TCP协议负责 稳定性，TCP为每一个包裹分配序列号 --> 被裹上TCP等协议；只收到了4个包裹，排序发现只收到了1，3，4，5，漏了个2；珠海PC的传输层向广州PC发送请求，重新发送2号包裹
    - TCP（可靠传输）或 UDP（不可靠传输）
3. 网络层：被裹上IP协议，IP头包含了源IP地址（广州PC的IP）和目标IP地址（珠海PC的IP）。
4. 数据链路层：被以太网协议包裹，以太网帧的头部包含了源MAC地址和目标MAC地址。节点到节点之间的传输，包裹上写上收件人，发件人，以及 两人之间的小秘密
    - 以太网协议：包含收件人，发件人，内容，以及 两人之间的小秘密（确保是对方，校验信息，防止信息被篡改）
    - 同一条链路上节点到节点之间的传输过程
      1. 以太网帧头部：发件人是广州PC网卡mac地址，收件人是广州局域网网关的的Mac地址 ---> 数据要离开广州PC所在的局域网（去下一个节点）

      2. 中山路由器接收到帧：发件人是中山路由器当前转发接口的MAC地址，收件人是中山局域网内，通往珠海方向的下一个设备的MAC地址 ---> 一直这样，直到数据到达珠海的网络边界，并最终被送到珠海PC（去下一个节点）
         - 检查帧头：发现收件人MAC地址是自己的MAC地址
         - 进行帧校验： 确保数据未被篡位。
         - 解封装（数据链路层）： 剥离以太网帧头部，得到内部的IP数据报。
         - 内容：IP数据报。
         - 查看目的IP地址是谁，根据路由表确定发送路径
              - 帧：数据链路层的基本单位；就是把网络层的包裹封装一层以太网协议而形成的大包裹叫帧。（因为层的不一样，才区分包或者帧，但其实是一个意思）

      3. 从珠海网络边界路由器到珠海PC：
         - 发件人MAC地址： 珠海网络边界路由器的MAC地址
         - 收件人MAC地址： 珠海PC的MAC地址
         
      4. 珠海PC接收和重组：
         - 数据链路层（珠海PC）： 收到帧，发现收件人MAC是自己的。校验帧，剥离帧头部，得到IP数据报。
         - 网络层（珠海PC）： 检查IP数据报头，发现目标IP是自己的。剥离IP头，得到TCP段。
         - 传输层（珠海PC）：
             - 根据TCP头中的序列号，对接收到的TCP段进行排序。
             - 此前提及漏掉的“2号包裹”在这里触发了重传机制（如上所述）。一旦所有段都按顺序收到并确认，就将它们重新组合成原始的应用层数据。
         - 应用层（珠海PC）： 接收到重组好的数据（例如HTTP请求），并进行相应的处理（显示网页内容等）。




### 3. **核心组件关系：**
*   **因特网公司:**
    - 因特网：又叫公网，有了公网IP才能上网）
*   **运营商 (ISP):** 提供互联网服务。 
    - 从因特网公司买来的网再卖给我们
*   **光猫 :** 将运营商的信号（光或电）转换成家里设备能用的信号，是你家上网的“钥匙”。
    - 光猫里的NAT技术和协议将IP地址转为mac地址
    - 因特网是高速公路的话 光猫就是特殊的收费站，给我们一个身份（公网IP）就能上高速公路（上网）。**特殊的点在于：给的身份是有限的（如果只给一个身份，那就是只有一台车上高速）。**身份是轮流用的：为什么商场的网络会很卡，因为人太多，切换身份的速度变慢了。
    - 发信息，光猫将我们的内网IP转为公网IP
*   **路由器 (Router):** 家里网络的“大脑”，连接光猫和所有设备。它负责“指路”，让数据在不同网络（比如你家网络和互联网）之间正确传输，以及分配家里的IP地址。
*   **交换机 (Switch):** 如果家里设备多，交换机（有时集成在路由器里）负责在同一个局域网内连接这些设备，让它们高效通信。
*   **网卡 :** 电脑、手机等设备的“身体接口”，让它们能连接到网络。每块网卡都有一个唯一的**MAC地址**。
*   **MAC地址:** 网卡的“身份证”，全球唯一，用于在**同一个局域网内**精确找到某台设备。
*   **IP地址:** 设备在网络中的“门牌号”，用于在**不同网络之间**定位设备。你家电脑通常有个内部IP（私网IP），路由器有个外部IP（公网IP）连着互联网。
*   **以太网协议:** 一套规则，规定了怎么用MAC地址在同一个局域网里发送数据（比如怎么打包成“帧”）。
