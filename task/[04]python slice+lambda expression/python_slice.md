# List 和 String 切片教程

## 一、切片简介

切片（Slicing）是 Python 中一种非常强大的操作，用于从序列（如字符串、列表等）中提取子序列。通过指定起始索引、结束索引和步长，可以灵活地获取所需的子序列。切片操作不仅适用于字符串，同样也适用于列表（List）。

## 二、切片语法

切片的基本语法如下：

```python
sequence[start:end:step]
```

- `sequence`：可以是字符串（`str`）或列表（`list`）。
- `start`：切片的起始索引（包含），默认为 0。
- `end`：切片的结束索引（不包含），默认为序列的长度。
- `step`：步长，默认为 1。

## 三、String 切片

### 1\. 基本操作

字符串切片可以从字符串中提取子字符串。字符串是不可变的，因此切片操作不会修改原始字符串，而是返回一个新的字符串。

#### 示例 1：基本切片

```python
s = "Hello, World!"
# 提取从索引 0 到索引 5 的子字符串（不包含索引 5）
print(s[0:5])  # 输出：Hello
# 提取从索引 7 到字符串末尾的子字符串
print(s[7:])  # 输出：World!
# 提取整个字符串
print(s[:])  # 输出：Hello, World!
```

#### 示例 2：步长的应用

```python
s = "abcdefgh"
# 提取从索引 0 开始，每隔一个字符的子字符串
print(s[::2])  # 输出：aceg
# 提取从索引 1 开始，每隔两个字符的子字符串
print(s[1::3])  # 输出：bdf
# 提取从索引 7 开始，向左每隔两个字符的子字符串（步长为负数）
print(s[7:0:-2])  # 输出：hfdb
```

#### 示例 3：负索引的使用

```python
s = "Python"
# 提取从倒数第二个字符到字符串末尾的子字符串
print(s[-2:])  # 输出：on
# 提取从索引 0 到倒数第二个字符的子字符串
print(s[:-2])  # 输出：Pyth
```

## 四、List 切片

### 1\. 基本操作

列表切片可以从列表中提取子列表。与字符串类似，列表切片不会修改原始列表，而是返回一个新的列表。由于列表是可变的，因此可以通过切片操作修改列表的某些部分。

#### 示例 1：基本切片

```python
lst = [1, 2, 3, 4, 5, 6, 7, 8, 9]
# 提取从索引 2 到索引 5 的子列表（不包含索引 5）
print(lst[2:5])  # 输出：[3, 4, 5]
# 提取从索引 5 到列表末尾的子列表
print(lst[5:])  # 输出：[6, 7, 8, 9]
# 提取整个列表
print(lst[:])  # 输出：[1, 2, 3, 4, 5, 6, 7, 8, 9]
```

#### 示例 2：步长的应用

```python
lst = [1, 2, 3, 4, 5, 6, 7, 8, 9]
# 提取从索引 0 开始，每隔一个元素的子列表
print(lst[::2])  # 输出：[1, 3, 5, 7, 9]
# 提取从索引 1 开始，每隔两个元素的子列表
print(lst[1::3])  # 输出：[2, 5, 8]
# 提取从索引 8 开始，向左每隔两个元素的子列表（步长为负数）
print(lst[8:0:-2])  # 输出：[9, 7, 5]
```

#### 示例 3：负索引的使用

```python
lst = [1, 2, 3, 4, 5, 6, 7, 8, 9]
# 提取从倒数第二个元素到列表末尾的子列表
print(lst[-2:])  # 输出：[8, 9]
# 提取从索引 0 到倒数第二个元素的子列表
print(lst[:-2])  # 输出：[1, 2, 3, 4, 5, 6, 7]
```

**示例输入**：`[10, 20, 30, 40, 50, 60]`

**示例输出**：`[20, 40, 60]`

**示例输入**：`[1, 2, 3, 4, 5, 6, 7, 8, 9]`

**示例输出**：`[4, 5, 6]`
- 答

#### 题目 4：列表分隔

给定一个列表，每隔 2 个元素插入一个分隔符（例如 `None`）。

**示例输入**：`[1, 2, 3, 4, 5, 6]`

**示例输出**：`[1, 2, None, 3, 4, None, 5, 6]`
- 原本写的
```python
print("None".join([j[i:i+3] for i in range(0,len(j),2)])) # 报错
```
     
#### 这里不能用join是因为 要求的输出是列表，而 join的输出是字符串（join和要求的输入都是列表）


- 答
```python
lst=[]
for x in range(0,len(j),2):
    lst.extend(j[x:x+2])
    if x+2<len(j):
        lst.append(None)
print(lst)
```

 8, 9]`

    result.extend(lst[i:i+2])
